# Mewgenics Script Resources

This repository acts as a set of helpful functions for modding Mewgenics. The aim of these files is to show the reader both the formatting of each major file type as well as the possible functions they can use, without overly explaining everything. To add or suggest changes, make your own personal branch and all responses from that branch will be read over before either accepting or denying the changes.

The file formats are split into 4 major sections:
